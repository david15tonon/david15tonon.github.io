Image simple, depuis le dossier `imgs/` du bundle :

```md

```

Ressource partagée, depuis la racine du dépôt :

```md

```

Pour une image légendée, une vidéo, un extrait audio ou une galerie, le HTML peut être placé directement dans ce fichier. Il n'est pas nécessaire d'ajouter des marqueurs de langue : ce fichier contient uniquement la version française.
